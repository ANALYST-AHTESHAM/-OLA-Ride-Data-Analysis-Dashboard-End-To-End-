🚖 OLA Ride Data Analysis Dashboard (Power BI)
📊 Project Overview
This is an end-to-end data analytics project built using Python, SQL, and Power BI to analyze OLA ride booking data. The project covers the complete workflow—from data cleaning and transformation using Python and SQL to interactive dashboard creation in Power BI.

It analyzes over 100K bookings and ₹34M+ revenue, providing insights into ride trends, customer behavior, payment methods, and cancellation patterns. The dashboard highlights a ~17.9% cancellation rate and consistent customer ratings around 4.0, helping identify key areas for operational improvement.

This project demonstrates strong skills in data processing, querying, and visualization, along with the ability to derive actionable business insights from raw data.

This project presents a comprehensive analysis of OLA ride bookings using Power BI. It provides insights into booking trends, revenue patterns, customer behavior, and cancellations.
